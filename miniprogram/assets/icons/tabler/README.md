Icons for the address step are sourced from [Tabler Icons](https://github.com/tabler/tabler-icons/tree/master/icons/outline).

Included icons: `package-export`, `map-pin`, `clock-hour-4`, `truck-delivery`, `calendar-event`, `chevron-right`, and `route`. Their `stroke` colors were adapted to the mini program's palette. See `LICENSE` for the MIT license and attribution.

The cargo step additionally uses `package`, `file-text`, `snowflake`, `tools-kitchen-2`, `first-aid-kit`, `dots`, and `alert-triangle` from the same set.

The address form also uses `user` and `phone` from Tabler Icons, with matching palette colors.
